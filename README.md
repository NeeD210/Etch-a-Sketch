## Etch-a-Sketch Project Documentation

This documentation provides an overview of the Etch-a-Sketch project, outlining its functionality and how to use it.

### Functionality

The Etch-a-Sketch project replicates the classic toy, allowing users to draw on a grid-based canvas. It provides the following features:

- **Drawing:** Users can draw on the canvas by hovering their mouse over the grid cells.
- **Resolution Adjustment:** The grid's resolution can be modified, allowing for different pixel sizes.
- **Color Customization:** Users can personalize both the sketch color and the background color.
- **Start Over:** A button is provided to clear the canvas and start drawing afresh.
- **Surprise Feature:** A 'Surprise!' button introduces a random color changing effect for a playful twist.

### Inputs

The project interface includes the following input elements:

- **Resolution Input Field:** Accepts numerical values to set the grid resolution. Ranges from 1 to 100.
- **Change Resolution Button:** Applies the entered resolution to the grid.
- **Sketch Color Input:** A color picker to select the desired drawing color.
- **Change Sketch Color Button:** Applies the selected color to subsequent drawing actions.
- **Background Color Input:** A color picker to choose the background color of the canvas.
- **Change Background Color Button:** Updates the canvas background with the chosen color.
- **Start Over Button:** Resets the canvas to its initial state.
- **Surprise Button:** Activates the random color changing effect.

### Outputs

The project generates a dynamic Etch-a-Sketch grid based on user inputs. The output is a visual representation of the user's drawing actions, reflecting the selected colors and grid resolution.
